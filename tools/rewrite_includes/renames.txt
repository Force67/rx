# Every header and symbol rx has renamed since the code-structure work began
# (docs/STRUCTURE.md), oldest first. A project on an older rx runs
#   tools/rewrite_includes/rewrite_includes.py <its source dirs>
# once after bumping; lines are idempotent, so running it twice is harmless.
#
#   include <old> <new>   an #include "<old>" becomes #include "<new>"
#   prefix  <old> <new>   an include starting with <old> gets <new> instead, if
#                         the result exists in this rx checkout
#   symbol  <old> <new>   a qualified name, matched as a whole word
#
# Includes are resolved through the whole table, so a header renamed twice
# lands on its latest path.
